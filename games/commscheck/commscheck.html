HEARING · SPEECH IN NOISE
COMMS CHECK
  • Mission Control sends a 3-digit code through radio static, into ONE earphone.
  • Type the 3 digits you heard: number keys or the keypad on screen.
  • Decode it and the next code has MORE static. Miss, and the static drops.
  • It's meant to get hard: the static rises until you miss about half. Can't make it out? GUESS.
  • One ear at a time, about a minute each. Don't touch the volume.

Why: constant fan noise on the station can slowly damage hearing, and normal beep tests need a quiet room. This checks the skill astronauts rely on most: understanding speech through noise.
